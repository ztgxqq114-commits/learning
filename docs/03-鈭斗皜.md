# 交接清單

> 每次換維護者時，**交出方和接手方一起**逐項確認並打勾，完成後把這份清單存到 `handover/日期-交出方-接手方.md`。

## 帳號

- [ ] 接手方能用 Google 共用帳號登入
- [ ] 接手方能編輯內容試算表，並實際上架、下架過一個單元
- [ ] 接手方是 GitHub Organization 成員
- [ ] 密碼已當面移交，交出方的個人帳號權限已移除

## 檔案

- [ ] 雲端硬碟所有資料夾的擁有者都是立德共用帳號（不是個人帳號）
- [ ] 內容試算表仍在「發布到網路」狀態，網站正常顯示
- [ ] 授權紀錄完整，對得上已上架的影片

## 實作確認

- [ ] 接手方**獨立**依 [新增單元 SOP](01-新增單元SOP.md) 上架一個單元（交出方只看不幫忙）
- [ ] 卡關的地方已記錄，並更新到 SOP 或常見問題
