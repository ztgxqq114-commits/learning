# 立德學習平台

> 立德計畫歷屆課程與工作坊影片的學習平台。學員可以依三大主軸找課程，看影片、跳章節、讀重點，再用小測驗確認自己學會了。
>
> **接手的學弟妹：上架新課程只需要改 Google 試算表，不用碰程式碼。** 從 [新增單元 SOP](docs/01-新增單元SOP.md) 開始看。

## 平台怎麼運作

```
   Google 試算表（課程內容）          YouTube（不公開影片）
   ・「單元」分頁                            │
   ・「測驗」分頁                            │
          │ 發布成 CSV                       │ 嵌入
          ▼                                  ▼
   ┌────────────────────────────────────────────┐
   │  學習平台網站（本 repo，放在 GitHub Pages） │ ◀── 立德官網放一個連結
   │  ・課程目錄、搜尋、學期篩選                 │
   │  ・播放頁：章節跳轉、重點筆記、講義         │
   │  ・內嵌測驗：即時解析、標記完成、進度條     │
   └───────────────────┬────────────────────────┘
                       │ 測驗成績（選填）
                       ▼
               Google 表單 → 作答紀錄試算表
```

| 工具 | 用途 | 費用 |
|---|---|---|
| Google 試算表 | 課程內容的「後台」 | 免費 |
| YouTube | 存放影片（不公開） | 免費 |
| GitHub Pages | 網站本體 | 免費 |
| Google 表單 | 測驗成績紀錄（選填） | 免費 |

**所有帳號都屬於立德共用帳號，不使用個人帳號。** 詳見 [帳號與權限](docs/02-帳號與權限.md)。

## 檔案結構

```
index.html          網站入口（一般不用改）
css/style.css       外觀、顏色（換主題色改最上面的 :root）
js/config.js        ★ 設定檔：試算表網址、測驗紀錄表單
js/app.js           主程式（一般不用改）
data/               示範資料；config.js 沒填網址時會讀這裡
docs/               維護手冊
templates/          出題範本
images/             手冊用的截圖
handover/           每次交接的紀錄
```

## 在自己電腦上預覽

網站需要透過本機伺服器開啟，直接雙擊 `index.html` 會讀不到資料。

```bash
# 在這個資料夾裡執行
python -m http.server 8000
```

接著用瀏覽器打開 <http://localhost:8000>。

## 怎麼編輯這份手冊（不用學 git）

1. 在 GitHub 打開要改的檔案
2. 點右上角的鉛筆圖示 ✏️
3. 修改完後，在「Commit changes」寫一句改了什麼，按綠色按鈕送出

## 限制（請先知道）

- **沒有登入機制**：網站是公開的，只是不對外宣傳網址。只同意會員觀看的影片不能放這裡。
- **進度存在學員自己的瀏覽器**：換裝置、清除瀏覽資料，進度就會不見。成績紀錄以 Google 表單為準。
- **試算表發布後是公開的**：不要在試算表裡放個資或內部資訊。
